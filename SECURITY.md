# Security policy

Roven Finance is currently a read-only yield intelligence interface. It does
not request custody, token approvals, transaction signatures, seed phrases or
private keys.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in public issues. Contact the
Roven Finance team privately through the security contact published on
[roven.finance](https://roven.finance) and include:

- the affected route or component;
- clear reproduction steps;
- expected and observed behavior; and
- potential impact.

Reports are reviewed before public disclosure. Never include private keys,
seed phrases, access tokens or personal data in a report.

## Scope

The active scope is the application source in this repository and the
production deployment at [roven.finance](https://roven.finance). Third-party
wallets, RPC providers, protocols and block explorers follow their own security
policies.
